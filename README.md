## 🚀 Proyectos de Especialización System & Kernel (Programación de Bajo Nivel y SO)

Estos proyectos reflejan mi enfoque en la programación a nivel de sistema, la gestión de memoria, la concurrencia y la interacción directa con el kernel.

* **ft\_containers**: Reimplementación de algunas de las estructuras de datos fundamentales de la STL de C++ (ej., vector, map, stack).
* **ft\_printf**: Reimplementación de la función `printf` de la biblioteca estándar de C.
* **ft\_philosophers**: Resolución del problema de los filósofos cenando, explorando concurrencia con hilos, mutexes y semáforos.
* **ft\_minitalk**: Comunicación entre procesos (IPC) utilizando señales de Unix (`SIGUSR1`, `SIGUSR2`).
* **ft\_get\_next\_line**: Lectura de líneas desde un descriptor de archivo, manejando búferes.
* **ft\_libft**: Mi biblioteca base en C con funciones básicas de manipulación de memoria, cadenas y caracteres.
